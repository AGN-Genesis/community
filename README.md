# AGN · AI Guardian Network

**人类驱动 · AI 创造 · 守护者维系**

AGN（AI 守护者网络）致力于建设由人类、AI 与资源提供者共同参与的开放 AI 经济网络。当前处于设计与创世建设阶段，文档提案不代表功能已经上线。

[知识库](https://agn-genesis-knowledge.grainyfir2.chatgpt.site) · [报名](https://github.com/AGN-Genesis/community/issues/new?template=01-join.yml) · [认领任务](https://github.com/AGN-Genesis/community/issues/new?template=02-claim.yml) · [提交贡献](https://github.com/AGN-Genesis/community/issues/new?template=03-contribution.yml)

## 七个建设方向

| 方向 | 范围 |
| --- | --- |
| [DID](directions/did/README.md) | 身份、授权、凭证和跨设备身份连续性 |
| [Capability](directions/capability/README.md) | 能力声明、服务发现、报价和验收条件 |
| [Reputation](directions/reputation/README.md) | 能力证据、任务评价、信誉与抗作弊 |
| [Super-Agent](directions/super-agent/README.md) | 授权运行、任务规划、工具调用与协作 |
| [Guardian](directions/guardian/README.md) | 计算、存储、网络、维护与资源隔离 |
| [Economy](directions/economy/README.md) | 任务报价、资源计量、验收与结算 |
| [Governance](directions/governance/README.md) | 社区提案、决策、执行与可追溯治理 |

## 从报名到贡献

1. 使用 GitHub 账号提交报名表，选择方向，说明能提供的贡献和可投入时间。
2. 查看 [首批任务](TASKS.md)，提交认领申请并关联任务编号；维护者确认后开始执行。
3. 通过 PR 或可核验成果链接提交交付物，附验证步骤与限制。
4. 维护者按任务验收标准记录结果；被接受的贡献通过 Issue、PR 和审核记录关联保留。

报名不自动授予组织成员、代码写入、维护者、治理或资金权限。申请者可以只使用公开 GitHub 昵称；不要填写手机号、住址、身份证、密码或私钥。Issues 和 PR 是公开记录。

详见 [协作流程](CONTRIBUTING.md)、[行为规范](CODE_OF_CONDUCT.md) 和 [贡献记录](contributions/README.md)。
